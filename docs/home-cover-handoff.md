# Нүүр хуудасны ковер · Админ ба backend-д өгөх даалгавар

Нүүр хуудасны хамгийн дээд слайдерт нэг бүртгэл нэг слайд болно. Зүүн талд гарчиг, санал, үнэ, товч; баруун талд барааны зураг харагдана. Текстийг зураг дээр шатааж оруулахгүй. Доорх нь frontend-д холбосон API гэрээ. Admin болон backend дээр хэрэгжүүлсний дараа админ ковер сольж, нийтлэх бүрд frontend дахин deploy хийх шаардлагагүй.

## Backend-д өгөх ажил

Express-д `/api/home-covers` router бүртгэж, Mongoose-ийн HomeCover model үүсгэнэ. Нийтийн GET-ийг token шаардахгүй ажиллуулна. Удирдлагын бүх endpoint дээр одоо байгаа `middleware/requireSuperAdmin.js` ашиглана. Хамрах хүрээ нь дэлгүүрийн нийт нүүр хуудас.

| Метод ба зам | Үйлдэл | Амжилттай хариу |
|---|---|---|
| GET /api/home-covers | published бүртгэлүүд, sortOrder өсөхөөр, тэнцвэл _id өсөхөөр | 200, доорх JSON |
| GET /api/admin/home-covers | Бүх төлөв, ижил эрэмбэ | 200, ижил items хэлбэр, мөр бүрд status ба sortOrder нэмнэ |
| POST /api/admin/home-covers | Бүртгэл нэмэх | 201, {"item": хадгалсан бүртгэл} |
| PATCH /api/admin/home-covers/:id | Илгээсэн талбаруудыг өөрчлөх, төлөв ба дараалал мөн энд | 200, {"item": шинэчилсэн бүртгэл} |
| DELETE /api/admin/home-covers/:id | Ковер устгах | 204, биегүй |

### Админ form, хадгалалт ба шалгалт

| Админ дээрх шошго | Талбар | Дүрэм |
|---|---|---|
| Коверын зураг | imageUrl | Заавал. Upload амжилттай болсон HTTPS res.cloudinary.com URL. Тунгалаг PNG/WebP тохиромжтой. Ойролцоогоор 738 × 391 px талбайд багтана. |
| Загвар | theme | dark (бараан дэвсгэр, цагаан текст) эсвэл light (цайвар дэвсгэр). Анх dark. |
| Үнийн тайлбар | text.mn.eyebrow | Сонголттой, 60 хүртэл тэмдэгт. |
| Эхлэх үнэ (₮) | startPrice | Сонголттой, сөрөг биш тоо эсвэл null. Валютын тэмдгийг frontend нэмнэ. |
| Гарчиг | text.mn.title | Заавал, 1–100 тэмдэгт. |
| Саналын эхлэл / Онцлох текст / Төгсгөл | offer / highlight / suffix | Хэл бүрийн text дотор. Сонголттой, тус бүр 80 хүртэл тэмдэгт. Онцлох текстэд тэмдэгтийг нь оруулна, жишээ нь -35%. |
| Товчны текст / Очих хуудас | button / href | Товчтой бол монгол шошго (40 хүртэл тэмдэгт) ба /shop зэрэг дотоод зам хоёулаа заавал. Товчгүй бол хоёуланг хоослоно. Зам нэг /-аар эхэлнэ, //, урвуу налуу зураас, зай, удирдлагын тэмдэгт зөвшөөрөхгүй. |
| Зургийн тайлбар | alt | Сонголттой, 160 хүртэл тэмдэгт. Хоосон бол гарчиг ашиглана. |
| Дараалал | sortOrder | 0 ба түүнээс их бүхэл тоо. Бага утга эхэнд. Анхны утга 0. |
| Төлөв | status | draft буюу Ноорог (анхны төлөв), published буюу Нийтэлсэн. |

POST body нь дээрх жишээний items[0]-оос _id-г хасаад status, sortOrder нэмсэн объект. Сервер _id ба timestamps үүсгэнэ. PATCH дээр text ирвэл бүх хэлний объектыг бүтнээр солино. Нэг талбар засахад admin бусад орчуулгыг хамтад нь илгээнэ. Мөрүүдийг trim хийж, хадгалах эцсийн объектыг дээрх дүрмээр backend дээр шалгана. Англи, хятад орчуулга сонголттой. Нийтэлсэн ковергүй бол 200 ба `{"items":[]}` өгнө.

Алдааны body: `{"error":"VALIDATION_ERROR","message":"Гарчиг оруулна уу","field":"text.mn.title"}`. Буруу талбар/ID 400, танигдаагүй хэрэглэгч 401, эрхгүй 403, бүртгэл олдохгүй 404. Одоо байгаа эрх шалгах middleware-ийн алдааны мессежийг админ мөн уншина.

## Админ хөгжүүлэгчид өгөх ажил

1. Super Admin цэсэнд **Нүүр хуудас → Ковер** нэмнэ. Хүснэгтэд зураг, монгол гарчиг, дараалал, төлөв, Засах/Устгах үйлдэл харуулна. Хоосон үед “Ковер нэмэх” товчтой байна.
2. Нэмэх/засах form-д дээрх хүснэгтийн талбарууд болон Монгол, English, 中文 текстийн tab гаргана. Баруун талын зураг, зүүн талын текст, сонгосон загвар, товчтой preview харуулна.
3. Одоо байгаа Cloudinary upload mutation-д FormData-ийн image талбараар файл илгээнэ. Амжилтын хариуны data.url-ийг imageUrl болгоно. Upload үргэлжилж байх үед хадгалах товчийг идэвхгүй болгоно. Upload алдаатай бол өмнөх зургийг хадгална.
4. Ноорог хадгалах, Нийтлэх, Нийтлэлээс буулгах, Дараалал солих үйлдлийг дээрх POST/PATCH-аар хийнэ. Амжилтын дараа жагсаалтыг шинэчилнэ. Устгахын өмнө “Энэ коверыг устгах уу?” гэж баталгаажуулна.
5. Хадгалах үед “Ковер хадгалагдлаа”, нийтлэхэд “Ковер нийтлэгдлээ”, алдаатай үед серверийн message эсвэл “Ковер хадгалж чадсангүй” харуулна.

## Хүлээн авах шалгалт

- Хоёр ковер нэмээд зөвхөн нэгийг нийтлэхэд нийтийн API болон нүүр хуудсанд нэг нь гарна. Хоёуланг нийтлээд дарааллыг солиход эхний слайд өөрчлөгдөнө.
- Монгол хэл дээр жишээний гарчиг, ₮274, -35%, зураг, /shop товч зөв харагдана. Хэл солиход текст солигдоно. Үнэ 0 бол харагдана; null бол тус үнийг нуух ёстой.
- Энгийн хэрэглэгч удирдлагын endpoint-оор ковер өөрчлөх боломжгүй. Устгасан эсвэл ноорог ковер нийтийн жагсаалтад орохгүй.
- Бүх коверыг буулгавал нүүр хуудасны слайдер алга болно. API нэвтрэхээс өмнө эсвэл API алдаа өгвөл frontend өмнөх слайдуудаа харуулна. Амжилттай өгөгдлийг Next.js 60 секундээр дахин шалгадаг тул нийтэлсний дараах эхний хүсэлт кэштэй байж болно.
